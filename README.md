# debianGPU
Running Debian on Android using *Termux* and *proot-distro*, **with GPU acceleration** enabled.

# Quick start
**1. Copy that command**
```bash
git clone https://github.com/tycon4ik/debianGPU.git && cd debianGPU && bash setup.sh
```
**2.wait for installation (*proot-distro xfce4 mesa)***

**3.choose GPU acceleration**
1.VirGL (mail/xclipse)
2.Zink (snapdragon)
3.No acceleration (stable, but slowly)
